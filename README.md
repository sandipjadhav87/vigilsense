# VigilSense

Weather-Based Smart Sensor Calibration Recommendation System for PIDS.

## Features
- Live weather data using OpenWeatherMap API
- Rule-based sensor calibration recommendations
- Operator dashboard
- Weather logging
- Analytics-ready database

## Technology Stack
Python, Flask, SQLite, HTML/CSS

## Setup
1. Install Python 3.10+
2. Install dependencies:
   pip install flask requests python-dotenv
3. Create `.env` file with OpenWeatherMap API key.
4. Run:
   python app.py
